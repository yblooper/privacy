Quick Guide: Record, Save, And Load A Loop

Use this flow when you want to capture a practice loop and keep it available for the next session.

  1. Connect your guitar or audio source, then set Mic Gain so the input is loud enough without clipping.
  2. Optional: set the Metronome BPM and enable count-in from Settings if you want a silent count before recording starts.
  3. Tap REC to start recording. Play the riff, chord progression, or practice phrase you want to loop.
  4. Tap REC again to finish the recording and create the loop.
  5. Tap Save to store the current loop and practice setup in the selected slot.
  6. Tap Storage to review saved loop slots. Use Load to bring a saved loop back into the main screen.

Tip: Use Slot1 to choose the active preset slot before saving. This helps keep different practice setups organized.

Main Screen Overview

Top Navigation

The top row gives fast access to the main areas of the app: tuner, storage, saving, preset slot selection, and settings.

Practice Controls

The center area contains input gain, metronome BPM, the effects chain, and the currently selected effect controls.

Pedals

The large lower pedals are designed for quick use during practice: record a loop with REC and delete the current loop with DEL.

Button Legend

Button / Control Where It Is What It Does

DEL Main screen bottom pedal Deletes the current loop from the active working area.
Tuner Top navigation Opens the guitar tuner screen.
Storage Top navigation Opens the saved loop slots and file controls.
Save Top navigation Saves the current loop and practice setup to the selected slot.
Slot1 / Slot Selector Top navigation Selects the active loop or preset slot used for saving and loading.
Gear Top navigation Opens Settings.
Mic Gain Main screen upper panel Adjusts the input level used by audio features.
Metronome BPM Main screen upper panel Sets the practice tempo. Use the minus and plus controls to adjust it.
FX Pedals FX chain panel Select an effect such as Distortion, Chorus, Stereo, Delay, or Reverb for editing.
Bypassed Effect editor Turns the selected effect on or bypasses it.
Reset Effect editor Returns the selected effect to its default values.
Effect Knobs Effect editor Adjust parameters for the selected effect, such as gain, tone, level, mix, or time.

Common effect labels: Dist. Chorus Stereo Delay Reverb

Storage And Loop Slots

The Storage screen shows available loop slots. Each slot can hold a loop file and displays its status, length, size, and file path when available.

Load Loads the selected loop slot into the main screen.
Share Shares the loop file when a shareable saved loop exists.
Trash Deletes the saved loop from that slot.
Selected Shows which loop slot is currently active.

Use Trash carefully. A deleted loop may not be recoverable.

Guitar Tuner

The tuner listens through the microphone and shows whether the detected note is flat, sharp, or in tune.

E2 A2 D3 G3 B3 E4 Standard guitar string targets.
Auto / Manual Tune Switches between automatic note detection and manual string selection.
UP / DOWN Changes tuning mode or target selection when available.
Sensitivity Knob Adjusts tuner response sensitivity.

For best results, tune in a quiet room and let one string ring at a time.

Settings

Settings contains app information, appearance options, CPU meter visibility, recording count-in, metronome volume, and loop trim controls.

Skin Changes the visual theme of the app.
CPU Meter Shows or hides CPU usage information.
Reset All FX Returns all effects to their default values.
BPM 110 Resets or sets the metronome BPM to the default value.
REC Count-in Enables or disables a count-in before recording starts.
Metronome Volume Adjusts metronome loudness.
